# 练食清单 · 使用说明

一个**只给自己看**的健身食物小站:食物库(营养/搭配/简单做法)、按目标选食物、每日饮食记录与营养汇总。纯本地运行,不需要联网、不需要账号、不花钱。

## 怎么打开

**双击本文件夹里的 `index.html`**,就会在浏览器里打开。或者把整个文件夹拖进浏览器地址栏也行。

## 页面一览

| 页面 | 文件 | 作用 |
|---|---|---|
| 首页 | `index.html` | 今天进度、按目标选食物入口、常吃常看、组合灵感 |
| 食物库 | `foods.html` | 45 种食材,可搜索、按分类/目标筛选 |
| 食物详情 | `food.html?id=xxx` | 每 100g 营养、健身价值、搭配、简单做法、小贴士 |
| 选食物 | `select.html` | 目标→场景→忌口,三步生成推荐,可一键记入当天 |
| 基础代谢 | `bmr.html` | 性别/年龄/身高/体重/训练年限 → 估算基础代谢(Mifflin-St Jeor 公式) |
| 餐单计划 | `plan.html` | 手动填每日热量/蛋白/碳水/脂肪目标,勾选食物池,自动均分三餐算出每餐克数,并做结构体检与调整 |
| 今日记录 | `log.html` | 按餐次记录克数,自动汇总营养;支持改、删、导出/导入备份 |
| 收藏 | `saved.html` | 收藏的食材集中管理 |
| 关于 | `about.html` | 数据口径、免责声明 |

## 数据说明

- 营养按**每 100 克(可食部)**计算,详情页标注生/熟/干等口径;
- 数值为参考值(参考《中国食物成分表》及公开营养数据库),不同产地/品牌/做法有差异;
- 内容为健身营养日常参考,**不构成医疗建议**。

## 重要:记录会存哪 & 怎么备份

记录和收藏保存在**你打开它的那个浏览器**里(本地)。如果清除浏览器数据、换浏览器或换电脑,记录会丢。

养成习惯:进「今日记录」→ 页面底部「数据管理」→ **导出备份**,会下载一个 `练食清单备份-日期.json` 文件;以后点「导入备份」选这个文件即可恢复。

## 常见问题

- **打开没样式/没数据?** 请直接双击 `index.html` 用浏览器打开,不要只打开单个 js/css 文件。
- **想改名/改颜色?** 告诉我,我来改。
- **想加功能?** 例如每日热量目标、体重曲线、一周餐单——直接在对话里说。

## AI 营养师(试用版)

本地运行,API Key 只存在你电脑上,不进仓库、不进浏览器。

### 启动
1. Windows 双击 `启动AI营养师.bat`(或在项目目录执行 `node server/index.mjs`);
2. 电脑打开 `http://localhost:8787/coach.html`;
3. 手机连同一个 WiFi,打开启动时提示的局域网地址,例如 `http://192.168.x.x:8787/coach.html`。

### 接入真实模型
1. 打开项目里的 `.env`;
2. 把 `DEEPSEEK_API_KEY=` 后面填上你的 DeepSeek Key;
3. 把 `MOCK=1` 改成 `MOCK=0`;
4. 重新启动服务即可。未填 Key 时是“演示模式”,界面与流程都能跑通,但回答是占位内容。

### 能做什么
- 建档:性别/年龄/身高体重、训练目标与强度、频率与项目、饮食偏好与忌口、安全筛查;
- 生成长期计划:训练日 / 休息日两套模板(每餐食物、克数、时机、替换建议);
- 对话追问:今天练什么、这餐怎么换、外食怎么点;
- 一键按计划记入今日饮食记录,或把目标与食材带到「餐单」页。

### 安全边界
不诊断疾病、不替代医生或注册营养师、不给补剂具体剂量;遇到疾病、用药、孕产哺乳、进食障碍、体重骤降或月经异常等情况,会建议你就医并只给一般性信息。

### 成本
每次调用会记录到 `server/usage.log`(token 与估算费用),可在页面右上角与「AI 营养师」页底部看到本次花费估算。价格系数在 `.env` 里可改(默认输入 ¥2/百万 tokens、输出 ¥8/百万 tokens)。
